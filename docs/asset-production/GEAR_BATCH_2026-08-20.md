# GalaQuest Gear Production Batch — 2026-08-20

## Purpose

Coordination ledger for the first post-Forge mass gear production wave. All items are **candidate-only** and remain subject to Forge fitting, animation review, Character Studio QA, running-game review, and owner acceptance before any production promotion.

Accepted Dawnwarden Helmet/Sword placements are not part of this batch and must not be changed by this work.

## Budget authority

Owner authorized up to **800 Meshy credits** for this production push.

Planned first-wave allocation:
- 35 concept images x 3 credits = 105 credits
- 28 high-visibility Meshy 6 Image-to-3D jobs x 20 credits = 560 credits
- 7 lower-kit Meshy 5 Image-to-3D jobs x 5 credits = 35 credits
- First-wave planned spend = 700 credits
- Contingency reserve = 100 credits

Do not spend the reserve blindly. Replacement generation must be justified by a visible defect or clearly weak result in the first-wave output.

## Art direction

Prioritize gameplay-distance impact: strong silhouette, large readable plates, one dominant focal point, large weapon/shield forms, bold material/color separation, and minimal low-value micro-detail.

Seven intentionally distinct families:
1. Embermaw — obsidian dragon / ember / molten gold
2. Frostfang — glacier silver / crystal / cyan
3. Stormwing — cobalt eagle / lightning / silver
4. Voidstar — black-violet cosmic / amethyst / cyan starfire
5. Wildthorn — forest steel / bronze bark / stag-antler / emerald
6. Sunlion — ivory / radiant gold / lion / solar light
7. Behemoth — colossal stone-and-bronze juggernaut / orange runes

Each family has five atomic candidate pieces: helmet, upper armor shell, lower armor kit, primary weapon, shield.
